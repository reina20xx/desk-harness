# Desk Harness — Autonomous AI Helpdesk & RAG Ticket Resolution Engine

**Desk Harness** replaces expensive per-seat & per-resolution helpdesk SaaS (Zendesk / Intercom / Helpfeel) with a **¥0/month Cloudflare Workers + D1 + RAG + MCP** autonomous customer support engine.

## Quick Start
```bash
git clone https://github.com/reina20xx/desk-harness.git
cd desk-harness
npm install
npm run dev
```
Open `http://localhost:8802` to test autonomous RAG ticket triage, Stripe refund policy verification, and P0 escalation lock.
